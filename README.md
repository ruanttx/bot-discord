# Privacy Policy – Bot do Ruan

**Last updated:** 13 August 2026

This Discord bot collects and processes only the minimum data required for its functionality.

## Data Collected

* Discord User ID
* Discord Server ID
* Channel ID
* Role ID

## Message Content

Message content is processed only to execute bot commands and moderation features. Messages are not permanently stored and are not used to train AI models.

## Data Usage

The collected data is used exclusively for:

* Automatic role assignment
* Verification and authentication
* Ticket system
* Moderation and server management
* Server configuration

## Data Sharing

We do not sell, rent, or share user data with third parties.

## Contact

For questions regarding this Privacy Policy, contact the server administrator.
